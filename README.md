# ⚡ OctoEnergy

A free, open-source PWA dashboard for Octopus Energy (UK) customers.  
Track your electricity and gas usage, costs, and tariff rates — all from your browser.

## Features

- 📊 30-minute interval heatmap for today's usage
- 📈 Daily / weekly / monthly trend charts
- 💷 Cost calculations (Fixed, Agile, Tracker tariffs)
- 🔐 API key stored locally in your browser — never sent anywhere else
- 💾 Export / import config as JSON backup
- 🌐 English / 中文 bilingual UI
- 📱 PWA — installable on mobile and desktop

## Setup

1. Go to [octopus.energy/dashboard/developer](https://octopus.energy/dashboard/developer) to get your API key
2. Find your MPAN and meter serial number on your bill or Octopus dashboard
3. Open the app and follow the 4-step setup wizard

## Deploy your own

Fork this repo → enable GitHub Pages (Settings → Pages → Source: GitHub Actions) → push to `main`.

## Tech stack

React 18 · TypeScript · Zustand · Vite · TailwindCSS · Recharts · GitHub Pages
